# Dashboard de Clima ⛅️

Projeto desenvolvido com o objetivo de praticar conceitos de React em um app simples e funcional de previsão do tempo.

O foco do projeto foi trabalhar componentização, hooks e custom hooks, consumo de API, estados de carregamento/erro e organização básica de uma aplicação React.

## Tecnologias

- React
- HTML
- CSS
- JavaScript
- Vite
- API da Open-Meteo

## Funcionalidades

- Busca de clima por cidade.
- Carregamento automático de uma cidade inicial (Rio de Janeiro).
- Exibicao do clima atual com temperatura, sensação térmica, umidade e vento.
- Exibição da previsão dos próximos dias.
- Ícones visuais de clima de acordo com o código retornado pela API.
- Tratamento de carregamento durante a busca.
- Tratamento de erro para cidade não encontrada ou falha na API.
- Layout responsivo para desktop e mobile.
